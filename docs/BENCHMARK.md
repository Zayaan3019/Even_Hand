# Benchmark: synthetic IIT Madras courses with known answers

Generated by `eh-validation`'s `Benchmark` (not part of the product; see [VALIDATION.md](VALIDATION.md) for how to run it, and for the validation on real double-graded answers). Deterministic: the same command reproduces every number. Per-course results: [`benchmark/test-results.csv`](benchmark/test-results.csv).

**Dataset.** 7 course shapes x 24 seeds for training and x 16 further seeds = 112 held-out test courses (16810 students in the test split). 144 training courses were used: those whose stated assumption the tool would accept (see `Benchmark.trainable`). A quarter of the courses have assistants who are truly identical, so false alarms can be counted.

**Training.** Grid search over the two shrinkage constants, minimising the mean error of the assistants' severities on the training split. Chosen: student 5, assistant 50 marks (training RMSE 1.18 percentage points).

*Grades truly moved*: share of students whose letter under the course's rule differs from the letter an average TA would have given them; known only in simulation. It is not zero for one-TA-per-question marking (SMALL_ELECTIVE): marks are bounded by zero and full marks, so a harsh TA there is harmless only to first order (ASSUMPTIONS A12), though about 4x less harmful than script-wise piles.

*Re-check precision*: of the scripts Even Hand flagged, the share whose grade really was changed by who marked them (known only in simulation). *Nearest-boundary precision*: the same number of scripts chosen the way moderation is done today, by closeness to a grade boundary.
