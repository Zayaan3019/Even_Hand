Did it matter which TA marked the script? Give Even Hand your marks file, with the students' written answers if you have them, and it tells you how differently each TA marked, whether what the students wrote explains it, which grades it moved, and which scripts deserve a second look. It never changes a mark.

What should the file look like?

One row per student (most mark sheets)

Write each question's maximum in brackets in its header. An answer column is optional and named like its question: Q1 answer, Answer Q1 or Q1 (response). Name and Total columns are ignored; a blank cell or AB means not answered. Several exams? Add an assessment column.

One row per answer (when TAs split by question)

roll_noassessmentquestionmax_marksmarkstaanswer
CE26B001Quiz 1Q1107RaviThe moment…

Column names are matched loosely: Roll No, roll-no and roll_no all work, and so do TA, marker, evaluator or Graded by. A script marked twice is welcome: it links two TAs directly.

Exam platforms, as exported

Moodle and other LMS quizzes: the grades or responses export with Q. 1 /10.00 columns (and Response 1 for the answers), plus a Graded by column.

Google Forms quizzes: the responses CSV, with its Score (31 / 40) and answer columns, plus a TA column.
